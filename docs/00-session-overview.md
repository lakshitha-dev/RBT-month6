# Month 6 — System Design & Architecture (Session Overview)

## Session Overview

| Attribute     | Details                                                  |
|---------------|----------------------------------------------------------|
| Duration      | 4 hours                                                  |
| Track         | Engineer                                                 |
| Focus         | System design, microservices, architecture documentation |
| Prerequisites | Months 1–5 completed                                     |

## Learning Objectives

By the end of this session, participants will be able to:

- Design scalable system architectures
- Create C4 model architecture diagrams
- Implement microservices patterns
- Set up API gateway and service discovery
- Present technical designs effectively

## Session Agenda (4 Hours)

### Hour 1: System Design Principles (60 min)

**Architecture Fundamentals (30 min)**
- Scalability patterns (horizontal vs vertical)
- CAP theorem implications
- Microservices vs monolith trade-offs
- Event-driven architecture

**C4 Model Overview (30 min)**
- Context diagrams
- Container diagrams
- Component diagrams
- Code diagrams

### Hours 2–3: Capstone Challenge (120 min)

**Challenge: Design Social Media Platform**

```
Platform: Social media application
Scale: 1M+ users
Features: Posts, feeds, notifications, messaging
Requirements: High availability, low latency
```

**Part 1: System Design (45 min)**
1. Gather requirements and constraints
2. Create high-level architecture
3. Design data models
4. Plan for scalability

**Part 2: Architecture Documentation (35 min)**
5. Create C4 Level 1 (Context)
6. Create C4 Level 2 (Container)
7. Create C4 Level 3 (Component for core service)
8. Document key decisions

**Part 3: Microservices POC (25 min)**
9. Implement 3 core services
10. Set up API gateway
11. Add service discovery
12. Implement circuit breakers

**Part 4: Presentation Prep (15 min)**
13. Prepare 15-minute presentation
14. Create talking points
15. Anticipate questions

### Hour 4: Presentations & Graduation (60 min)

**Individual Presentations (40 min)**
- 8–10 min per participant
- Architecture walkthrough
- Design decision justification
- Q&A

**Program Review (15 min)**
- 6-month journey recap
- Skills assessment
- Next steps

**Graduation (5 min)**
- Certificate presentation
- Senior Engineer pathway
